# Only a type's own deprecation marks the OpenAPI document

The `Deprecation` and `Sunset` headers resolve a type's own `deprecation` and `sunset` over its server's `defaults` and then `jsonapi.defaults`, but the OpenAPI document reads only what the type's class declares, so a global `deprecation: true` sends the header everywhere and marks nothing. A default deprecates a whole running API version, which a client already learns from the header and from choosing that server's document, while marking every operation of every type would bury the types an author picked out; it also keeps the Symfony bundle, which makes the same choice, byte-compatible. Operations deprecated on their own share the header machinery, sending `Deprecation: true` from the same registry, so the document and the headers can't disagree about them.
