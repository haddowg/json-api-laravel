# Declared link rows are queried and written by the data layer from their fields

An identified `MorphToMany` declared with `identifiedByRows()` names its row model and the row's owner, type and id fields, so the Eloquent provider queries the rows in SQL from those fields alone, narrowing a scoped member type to its admitted keys in the same query, and the persisters apply core's `LinkRowWritePlan` themselves rather than leaving the rows to `fillUsing()`: one declaration then fixes which rows count, their order and their writes on every provider, the bundle's included. A relation declared with an `identifiedBy()` closure hides its rows, so it is served in memory, `jsonapi:optimize` says so, and its `fillUsing()` hook still owns which rows exist, with the pivot values a write sends landing on those rows after it.
