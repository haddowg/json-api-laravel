# Operation extensions take case values and operation names in one map

`operationExtensions` was keyed by `Operation` case value, so it could only reach the five CRUD operations, and a feature-gated relation needed a way to tag one related endpoint. Rather than add a second attribute argument, the same map also takes core's operation names, such as `fetchRelated.agencies`; the two spellings can't collide because case values are PascalCase and names are camelCase, and `TypeMetadata` routes case values to core's CRUD seam and names to `DeclaresNamedOperationExtensions`, so the discovery snapshot keeps its shape and every existing declaration projects as before. Since `Create` and `create` mean the same operation and core would layer one over the other silently, naming an operation both ways fails at discovery instead.
