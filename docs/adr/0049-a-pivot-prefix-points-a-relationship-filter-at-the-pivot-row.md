# A pivot prefix points a relationship filter at the pivot row

A pivot relation's members can need filtering by what hangs off the row that links them to this parent, such as definitions a template uses whose row has no targets, which no filter on the member can answer once a member is shared. As in the bundle, a `pivot.` prefix on the relationship of `WhereHas` and `WhereDoesntHave` or the path of `WhereThrough` and `WhereThroughIn` starts the filter from the row, so it is declared, routed and documented the way pivot column filters already are. The Eloquent provider asks the pivot model's relation for its existence query, the one `whereHas` builds, so the subquery correlates to the join row through the relation's own keys rather than through an alias the provider would have to guess.
