# Datetime bounds and writes use the default timezone

Eloquent formats a date-time as `Y-m-d H:i:s` for bindings and datetime casts and reads it back in PHP's default timezone, so a client value in `Z` or another offset compared or stored its own wall-clock time against local times. Filters and writes now convert a date-time to `date_default_timezone_get()` for a column with a built-in datetime cast, reading the zone each time because applications switch it per request, and writes are converted in the request body before hydration because Eloquent drops the offset the moment a value is assigned. A `date` cast is compared with `whereDate()` on the bound's own day instead, since converting a midnight bound can move it to the previous day, and an uncast or custom-cast column is left alone because its type is unknown.
