# Vendor extensions are declared on the resource attribute

Core's `DeclaresOperationExtensions` lets type metadata carry `x-` extensions for a type's operations, and the package exposes it as `extensions` and `operationExtensions` on `#[AsJsonApiResource]`, next to `tags` and the response overrides, rather than as a method hook on the resource. An extension is static documentation about the type, so it belongs with the other declarative OpenAPI settings, travels through the discovery cache as plain values, and is checked when the attribute is constructed: a key without the `x-` prefix, a reserved `x-oai-`/`x-oas-` key, a value the cache can't export, or a per-operation set for an operation the type doesn't expose fails discovery instead of producing a malformed or silently incomplete document.
