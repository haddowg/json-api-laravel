# The package registers the Field Selection profile and lets core narrow every render

Core decides which `fields[type]=<attribute>.<key>` members a type accepts, trims the rendered value and advertises the Field Selection profile from its responses, so this package appends `FieldSelectionProfile` to the default `jsonapi.profiles` after the three it already registered, in the bundle's order so the `jsonapi.profile` enum stays byte-identical, and adds no selection code of its own. The strict fieldset check runs in core's `Server` and every response renders through core's `toPsrResponse()`, so primary data, `included`, related endpoints, write responses and atomic results all narrow without a Laravel arm, and the pivot serializer decorator passes `getAttributes()` through to the resource that trims. Both providers load the model whole and core trims on render, because Eloquent has no per-key read of a `json` column; a reader that wants to read less does so in an `extractUsing()` hook, which receives the selected keys.
