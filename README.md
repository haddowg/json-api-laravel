# json-api-laravel

Laravel package for [haddowg/json-api](https://github.com/haddowg/json-api): idiomatic
routing, content negotiation, validation, and an Eloquent data layer for spec-compliant
JSON:API 1.1 endpoints.

> **Work in progress** — pre-release. See the
> [Symfony bundle](https://github.com/haddowg/json-api-symfony) for the equivalent
> integration this package mirrors.
